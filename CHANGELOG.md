# Prism changelog

## 1.0.0 — initial local candidate

- One shared JSON/XML viewer, with virtualized rows and local worker processing.
- Field, path, case-sensitive and bounded regular-expression search.
- Tree/raw views, document analysis, clipboard/download and error recovery.
- Central design tokens and generated Prism icon family.
- Browser builds, Changesets, package verification and deterministic candidate archives.

Chromium, Edge and Firefox integration checks have run on one machine (see docs/verification.md). Final visual review, reproducible archives, dependency audit, independent review and store publication remain open.

# Store listing draft

Name: Prism — JSON & XML Viewer

Summary: Explore JSON and XML in one local desktop workspace with search, paths, raw source and document analysis.

Description: Read structured documents through a virtualized tree. Search keys, tags, attributes, values or paths; navigate matches and inspect full values in a dedicated rail. Copy a path or value, switch to raw source, and download the acquired document. Choose light, dark or high-contrast themes. Open a local file or paste content when automatic detection is unavailable.

Privacy: Processing happens locally. No accounts, tracking or document uploads. Only supported display preferences persist.

Permissions: `storage` saves preferences. HTTP(S) content scripts detect confidently identified raw documents and mount the viewer. There are no cookie, history, debugger, native messaging or remote-code permissions.

Limitations: desktop only; protected browser pages cannot host the viewer; XML may be labeled reconstructed; JSON tree precision/duplicate keys can differ from raw source. Source, node, depth and processing-time limits apply. No editing, schema validation or full XPath evaluator is advertised.

Publication status: source available after authorized repository push; store upload/submission/approval have not occurred. Choose publisher accounts and host/confirm the policy URL before submission.

# Feature parity and scope

| Capability | Prism |
|---|---|
| JSON and XML tree | Shared flat model and virtual renderer |
| Namespaces, attributes, mixed content, CDATA, comments, processing instructions | XML SAX adapter |
| Search fields, case, regex, previous/next | Shared worker search; XML-specific field choices |
| Path text search | Supported; not an XPath evaluator |
| Raw source / copy / download | Shared viewer and platform actions |
| Analysis | Node-kind counts and maximum depth |
| Legacy top-tag/attribute frequency, largest-element summaries | Deferred; not advertised as implemented |
| Themes | Light, dark, high contrast |
| Narrow desktop | Shared workspace with wrapping search controls |
| Mobile-specific UI | Removed by product scope decision |
| Schema validation / editing / diff | Out of scope |
| Browser-native XML | Reconstructed source disclosed; browser verification tracked separately |
| Legacy store IDs/settings migration | No automatic migration |
